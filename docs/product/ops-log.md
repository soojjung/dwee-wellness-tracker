# dwee 운영 로그

TestFlight·출시 이후 **무슨 일이 있었고 무엇을 했는지** 시간순으로 남기는 기록. 항목별 통과 여부는 [testflight-checklist.md](./testflight-checklist.md) 가, 출시 계획은 [release-plan-v1.md](./release-plan-v1.md) 가 원본이고, 이 문서는 그 사이의 사건·원인·조치를 적는다.

작성 규칙

- 라운드(빌드) 단위 절. 새 빌드를 올리면 "빌드 이력" 표에 한 줄 + 새 라운드 절을 연다.
- 피드백 1건 = 표 1줄. 번호는 라운드마다 1부터 (`R3-1` 처럼 참조). 커밋 메시지에도 같은 번호를 쓴다.
- **원인**은 추측이면 "추정" 을 붙이고, 확인되면 고친다. 재현 못 한 건은 상태 `관찰` 로 남긴다.
- 코드 밖 조치(콘솔 설정, Supabase SQL, Sentry, App Store Connect)는 "운영 조치" 표에 적는다 — git 에 흔적이 안 남는 것들.

상태: `수정` 커밋됨 · `확인` 다음 빌드에서 실기기 확인 완료 · `관찰` 재현 대기 · `보류` 이번 릴리스에서 안 함 · `재발` 확인 후 다시 발생
